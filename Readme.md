# Animated Authentication UI

## Description

A professional and responsive authentication UI containing Login and Signup pages. The project is built using HTML5, CSS3, Bootstrap 5, Bootstrap Icons, and JavaScript.

## Features

* Professional layout
* Responsive design
* Login page
* Signup page
* Background image
* Blurred Login and Signup blocks
* Bootstrap 5
* Bootstrap Icons
* Modern typography
* Fade animations
* Hover effects
* Focus effects
* Scale effects
* Smooth transitions
* Animated Login and Register buttons
* Show/Hide password
* Password validation
* Confirm Password validation
* Special character validation
* Error messages for invalid passwords

## UI Design

* Full-page background image for a modern appearance
* Glassmorphism-style blurred Login and Signup blocks
* Smooth transitions and visual effects for better user experience
* Responsive authentication layout for different screen sizes

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* JavaScript

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Select Login or Sign Up.
4. Use the authentication forms.

## Signup Validation

The Signup form checks:

* Password must contain at least one special character.
* Password and Confirm Password must match.
* Error messages are displayed below the relevant fields.

## Note

This project is frontend only. No database or backend authentication is implemented.
